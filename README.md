# CPicker

<p align="center">
  <img src="logo.png" alt="CPicker" width="150">
</p>

A lightweight Linux screen color picker that instantly returns the RGB and HEX value of any pixel you click.

> **Linux / X11 only**

## Installation

```bash
git clone {link}
cd CPicker
chmod +x CPicker
echo "export PATH=\"\$PATH:$(pwd)\"" >> ~/.bashrc
source ~/.bashrc
```

## Usage

```bash
CPicker
```

Click anywhere on the screen to get the color.
